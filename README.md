# 🎬 Sentiment Analysis — IMDB Movie Reviews

> Data Science Project | NLP | Machine Learning  
> Full pipeline: EDA → Preprocessing → Modeling → Streamlit Deployment

---

## 🎯 Objective

Automatically classify movie reviews as **positive** or **negative** from raw text.

This project covers the full Data Science lifecycle:
- Exploratory data analysis and visualization (EDA)
- Text cleaning and preprocessing
- TF-IDF vectorization
- Comparison of 3 Machine Learning models
- Web interface deployed with Streamlit

---

## 📊 Dataset

**IMDB Movie Reviews** — 50,000 English movie reviews  
- 25,000 positive / 25,000 negative (balanced dataset)  
- Source: [Kaggle](https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews)

## 🚀 Usage

### 1. Download the dataset

Place `IMDB_Dataset.csv` in the `data/` folder.  
[Download from Kaggle](https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews)

### 2. Explore the data (EDA)

```bash
jupyter lab notebooks/exploration.ipynb
```

### 3. Train the model

```bash
python src/train.py
```

Generates:
- `models/sentiment_model.pkl` — trained model
- `data/confusion_*.png` — confusion matrices
- `data/top_words.png` — most discriminating words

### 4. Launch the Streamlit app

```bash
streamlit run app.py
```

## 📈 Results

| Model | Accuracy | AUC-ROC |
|-------|----------|---------|
| **Logistic Regression** | **89.2%** | **96.1%** |
| Linear SVM | 89.0% | 95.8% |
| Random Forest | 85.3% | 93.4% |

> Logistic Regression offers the best trade-off between accuracy, interpretability, and speed.

## 🔧 Technical pipeline

```
Raw text
    │
    ▼
Cleaning (HTML removal, punctuation, lowercasing)
    │
    ▼
TF-IDF Vectorization (20,000 features, bigrams)
    │
    ▼
Logistic Regression
    │
    ▼
Predicted sentiment (Positive / Negative) + confidence score
```
